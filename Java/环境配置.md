# Mac

查看安装位置

```	shell
/Library/Java/JavaVirtualMachines
```



查看版本信息

```shell
java -version
```



.bash_profile

```shell
# 配置多版本jdk   begin
export JAVA_17_HOME=/Library/Java/JavaVirtualMachines/jdk-17.jdk/Contents/Home

alias jdk17='export JAVA_HOME=$JAVA_17_HOME'

export PATH=$JAVA_HOME/bin:$PATH:.
# 配置多版本jdk   end
```



保存

```shell
source ~/.bash_profile
```
